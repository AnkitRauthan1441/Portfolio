## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload/push **everything in this folder** to the repository's `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **GitHub Actions**.
5. Open the **Actions** tab and wait for `Deploy Next.js site to GitHub Pages` to finish.
6. Your site will be available at:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

The workflow automatically detects the GitHub repository name and configures the Next.js `basePath`, so you do not need to edit it manually.
